# Changelog

## 1.0.0 (2026)

Initial release of FileSight.

### Features

- **File Scanning** — Recursively scan and catalog all files in a directory with progress reporting.
- **Storage Insights** — Visual breakdown of storage by category (images, documents, archives, installers, etc.), largest files, old files, and storage overview.
- **Smart Suggestions** — Actionable recommendations for cleaning up old installers, large files, and stale archives.
- **Duplicate Detection** — Find duplicate files using hash-based content analysis with grouped results.
- **File Explorer** — Browse, search, filter, and sort scanned files with category, size, and date filters.
- **Safe Cleanup** — Preview and move files to system Trash/Recycle Bin with progress tracking.
- **Scan History** — Persisted scan results with trend charts, scan comparisons, and cleanup tracking.
- **Settings** — Configurable preferences for scanning, appearance, and privacy.
- **Onboarding** — First-launch wizard to guide new users.
- **Privacy** — Fully offline, no accounts, no telemetry, no cloud dependencies.

### Platforms

- macOS (DMG)
- Windows (NSIS installer)
- Linux (AppImage, deb)
