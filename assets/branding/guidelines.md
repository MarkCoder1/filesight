# FileSight — Brand Guidelines

## Product Identity

**Name:** FileSight
**Tagline:** Understand your files. Reclaim your space.
**Description:** A privacy-first desktop application for understanding and managing your files.

### Brand Personality
- Trustworthy
- Clean
- Modern
- Simple
- Secure
- Technical but friendly

### Core Message
A privacy-first tool that helps users understand and manage their files.

---

## Logo

### Primary Logo
Shield + Folder combination mark.
- Shield represents protection and security.
- Folder represents file organization.
- The shield sits inside the folder symbolizing that your files are protected.

### Logo Variants
1. **Full** — Shield icon + "FileSight" wordmark (sidebar, header)
2. **Icon** — Shield + Folder mark only (favicon, app icon, small spaces)
3. **Monochrome** — Single-color version for dark backgrounds

### Logo Usage
- Always maintain clear space around the logo equal to the height of the icon.
- Do not stretch, rotate, or recolor the logo.
- Use the primary color version on light backgrounds.
- Use the monochrome version on dark or colored backgrounds.

## Tone of Voice

### Do
- Use clear, concise language.
- Be reassuring about privacy and safety.
- Use technical terms only when necessary.
- Explain actions before requiring confirmation.
- Use positive framing ("Your files are organized" not "Your files are messy").

### Don't
- Use aggressive "cleaner" branding.
- Use scary warnings or alarmist language.
- Assume technical expertise.
- Use jargon without explanation.
- Make promises about file safety that cannot be kept.
